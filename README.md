# Cybersecurity Study

A personal archive of what I'm learning about cybersecurity, and especially about **where AI and security meet**.

## Why this repo exists

AI is changing both sides of security:

- **Attacks on AI systems**: prompt injection, poisoned RAG data, over-privileged agents, malicious MCP servers and model files.
- **Attacks powered by AI**: fluent phishing at scale, voice and video deepfakes, faster reconnaissance and exploitation.

To understand these threats well, I think you need both **AI engineering** knowledge (how LLM apps, RAG, and agents are built) and **security** knowledge (how systems are attacked and defended). So I'm studying the two side by side, loosely following the [AI Engineer](https://roadmap.sh/ai-engineer) and [Cyber Security](https://roadmap.sh/cyber-security) roadmaps from roadmap.sh, with the goal of becoming an engineer who can handle today's AI-driven threats.

## ⚠️ Please read: what this repo is (and isn't)

- **I'm not a security expert.** I'm a learner, and this is my study log.
- These are **notes to build up knowledge and to come back to later**, not an authoritative reference, a professional course, or security advice.
- The notes are my own summaries and interpretations. **They may contain mistakes, oversimplifications, or outdated information**, especially in a field that changes this fast. Always check against the original sources linked in each folder.
- Any code here is **for learning only**. Run it on your own machine, and only test systems you own or are explicitly authorized to test.
- Corrections are welcome. Feel free to open an issue.
